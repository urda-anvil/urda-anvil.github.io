Rules from the anvil, in plain Markdown. Save a file, or give its raw URL to your agent.

Rules are constant decisions, instructions, standards, and other constraints that shape how agents behave. They are stored, shared, and referenced as plain Markdown files so any agent can load them. Every rule from the anvil has its own section here, with background or important details included.

Each rule carries a tag for how it loads. An always-on rule stays in your session context the entire time. An on-demand rule sets its conditions in frontmatter, and it works best in a harness that can load it on demand.

Simplified Technical English always-on

Makes the agent write short sentences in the active voice, with one term for each concept. It covers replies, pull request text, and documentation. It does not touch code, quoted text, or tool output.

https://anvil.urda.com/forge/rules/raw/ste.md

This rule is a subset of ASD-STE100 Simplified Technical English, Issue 9, written for coding agents. It paraphrases the rules of the standard and cites their numbers. It does not contain the text of the standard or its dictionary, and it does not make output STE compliant. The standard is free from ASD: request a copy.
