Agent

An AI system that can choose steps and use tools to work toward a goal.

Example: You ask an agent to fix a bug. It reads the code, changes a file, and runs a test.

See also: Harness, Subagent, Tool

AI (artificial intelligence)

A broad name for computer systems that perform tasks such as recognizing speech, generating text, or identifying objects in images.

Example: You ask a chat app to plan a trip, and it writes a day-by-day schedule.

See also: LLM, Model

API (application programming interface)

A way for one program to request data or actions from another program. AI services offer APIs too, so your own code can send prompts and receive answers.

Example: The weather app on your phone uses a weather service's API to request today's forecast, then shows it to you.

See also: Token

CLI (command-line interface)

A program that you use by typing commands in a terminal instead of clicking in a window. Many AI agents come as a CLI that works on the files in the current folder.

Example: You type a command to list the files in a folder.

See also: Terminal, TUI, Balancing the Anvil

Context

The information available to the model for a response. This can include instructions, conversation messages, and tool results.

The context window limits how many tokens a model can use at once. An app may shorten or omit older material to fit.

Example: You give the model your room dimensions so it can suggest furniture that fits.

See also: Token, Subagent

Effort

How much thinking and work a model puts into a response. Higher effort gives it more room to work through a problem, but it can take longer and use more tokens.

Example: You choose high effort to investigate why your printer keeps disconnecting, and low effort to shorten a printer setup checklist.

See also: Model, Token, Effort per Model

Hallucination

An answer that sounds confident but is wrong or invented.

Example: You ask for a source, and the model gives a title and link for a paper that does not exist.

See also: Model

Harness

The software that lets a model work as an agent. It sends information to the model, runs the tools the model requests, and returns their results. It also manages permissions and approval prompts.

Example: The model requests a file edit. The harness asks for your approval and applies the edit if you approve.

See also: Agent, Sandbox, Tool

LLM (large language model)

A model trained on large amounts of text to process and generate language. Some models also work with images, audio, or video.

Example: You give an LLM meeting notes and ask it to extract the decisions and assigned tasks.

See also: Model, Token

MCP (Model Context Protocol)

An open standard that lets AI apps connect to external tools, data, and reusable prompts. The AI app connects to an MCP server, which provides access to those features. Because MCP is a shared standard, one MCP server can work with many apps that support MCP. An MCP server can run on your own computer or on another machine, on your local network or on the internet. Anyone can publish an MCP server, so connect only servers you trust.

Example: You connect your AI app to your issue tracker's MCP server. The app can then read a ticket and post a comment for you.

See also: Plugin, Tool, Anvil MCP catalog

Model

The trained system that processes input and produces output. An app can offer several models.

Example: You choose a different model in the same app to try another response.

See also: Effort, LLM, Balancing the Anvil

Plugin

An installable package that adds abilities to an AI app. It bundles parts such as skills, subagents, and MCP servers, so you can install them in one step. Some apps call these extensions. A plugin runs with your permissions, so install only plugins you trust.

Example: You install a design plugin. In one step, it adds a skill for checking layouts and an MCP server that reads your design files.

See also: MCP, Skill, Subagent

Prompt

The input you give a model to guide its response. A prompt can contain a question, instructions, or material to work with.

Example: Summarize this email in three sentences.

See also: Context, Rule

Rule

An instruction meant to guide behavior across tasks. A written rule does not guarantee compliance.

A rule describes expected behavior. A permission setting controls access to an action.

Example: Use short sentences in documentation. This guides each writing task without repeating the request.

See also: Prompt, Skill, Anvil Rules

Sandbox

A walled-off space where a program can run without reaching the rest of your computer. It works like a child's sandbox: you can make a mess inside, and the mess stays in the box. Web browsers and phone apps use sandboxes too. For an agent, a sandbox can limit the files, commands, and network access it gets. Files that the sandbox allows, such as your project folder, can still change.

Developers also use the word for a safe test copy of a service, such as a payment account with fake money.

Example: An agent runs a bad command inside a sandbox. It can still damage files in your project folder, but the rest of your computer stays safe.

See also: Agent, Harness, The riff bill of rights

Skill

A reusable package of instructions for a particular task. It can also include scripts, examples, and reference files.

The Agent Skills format uses a SKILL.md file. A product may also use the word skill for another feature.

Example: A report skill gives the agent a template and instructions for preparing a weekly report.

See also: Plugin, Rule

Subagent

An agent that another agent starts to handle one part of a task. It works in its own separate context, so its searches and file reads do not fill up the main conversation. When it finishes, it sends back a short summary. Several subagents can run at once, and their work still adds to your usage.

Example: An agent asks a subagent to search a large codebase. The subagent reads 40 files and returns a five-line list of the ones that matter.

See also: Agent, Context

Terminal

An app where you type text commands and read the text that comes back. A CLI or a TUI runs inside a terminal. macOS includes an app called Terminal, and Windows includes Windows Terminal. You can also install a different terminal app, such as iTerm2 for macOS.

Example: You open a terminal and type a command to move into your Documents folder.

See also: CLI, TUI

Token

A unit a model uses to process information. For text, a token can represent a word, part of a word, or punctuation. Pay-per-use AI APIs often charge by the number of tokens processed and generated.

Example: When you paste a recipe into a chat, the ingredient names, quantities, and punctuation all contribute to its token count.

See also: API, Context

Tool

In AI, a tool lets a model request an action, such as searching the web, reading a file, or running code. The surrounding software performs the action and returns the result. Tools can come built into the app or through connections such as plugins and MCP servers.

Example: You ask when you are free tomorrow. The model requests a calendar search and uses the results to suggest a time.

See also: Harness, MCP, Plugin

TUI (text user interface)

A full-screen app that runs inside a terminal. It has panels, menus, and prompts that you work with from the keyboard. Many agent CLIs open a TUI when they start.

Example: You start an agent in a terminal. It fills the window with a chat panel, a status line, and approval prompts.

See also: CLI, Terminal, Forged Status Line
